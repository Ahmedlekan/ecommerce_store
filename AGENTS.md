Requirements:
- Before running any command, explain in 1-2 simple sentences what
  you are about to do and why.
- Inspect existing code before modifying anything.
- Do not run terraform apply or terraform destroy automatically.
- Do not make destructive Kubernetes changes automatically.
- Explain AWS infrastructure changes before making them.
- Follow least-privilege IAM practices.
- Prefer existing infrastructure over creating duplicate resources.
- Run appropriate validation after code changes.
